# Формат файлу квізу

Файл має бути у форматі **JSON** із розширенням `.json`.

## Структура

Файл — це масив об'єктів. Кожен об'єкт — одне питання.

```json
[
  {
    "id": "1",
    "question": "Текст питання?",
    "options": [
      "Варіант A",
      "Варіант B",
      "Варіант C",
      "Варіант D"
    ],
    "correct_index": 0
  }
]
```

## Поля

| Поле            | Тип      | Опис                                                        |
|-----------------|----------|-------------------------------------------------------------|
| `id`            | string   | Унікальний ідентифікатор питання (може бути числом або рядком) |
| `question`      | string   | Текст питання                                               |
| `options`       | string[] | Рівно 4 варіанти відповіді                                  |
| `correct_index` | number   | Індекс правильної відповіді у масиві `options` (від 0 до 3) |

## Правила

- `correct_index: 0` → правильний варіант A (перший у списку)
- `correct_index: 1` → правильний варіант B
- `correct_index: 2` → правильний варіант C
- `correct_index: 3` → правильний варіант D
- Масив `options` повинен містити **рівно 4** елементи
- Усі поля обов'язкові

## Приклад з кількома питаннями

```json
[
  {
    "id": "1",
    "question": "Що таке REST API?",
    "options": [
      "Архітектурний стиль для побудови веб-сервісів через HTTP",
      "База даних для зберігання запитів",
      "Мова програмування для серверної розробки",
      "Протокол шифрування даних"
    ],
    "correct_index": 0
  },
  {
    "id": "2",
    "question": "Яка HTTP-відповідь означає 'не знайдено'?",
    "options": [
      "200",
      "403",
      "404",
      "500"
    ],
    "correct_index": 2
  }
]
```

## Підказка для генерації ШІ

Коли просиш ШІ згенерувати питання — уточни:
- **Тема** (наприклад: Flutter, SQL, алгоритми, системний дизайн)
- **Кількість питань**
- **Рівень складності** (junior / middle / senior)
- Попроси повернути **валідний JSON** без зайвого тексту навколо
