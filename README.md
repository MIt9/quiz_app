# Quiz App

Flutter-застосунок для проходження квізів із JSON-файлу. Підходить для підготовки до інтерв'ю: питання з 4 варіантами відповіді, історія результатів, пояснення від Gemini та озвучення питань.

## Можливості

- Імпорт квізу з JSON-файлу (`.json`), історія імпортованих файлів.
- Бібліотека квізів з GitHub: нові квізи підвантажуються без перезбирання застосунку (див. [quiz-library](https://github.com/MIt9/quiz-library)).
- Питання перемішуються випадково при кожному старті квізу.
- Пауза та продовження: прогрес зберігається після кожної відповіді.
- Історія пройдених сесій і результатів.
- Пояснення питання від Gemini простими словами (потрібен API ключ).
- Озвучення питань (TTS): швидкість, висота голосу та мова налаштовуються (за замовчуванням `uk-UA`).
- Світла та темна теми.

## Структура `lib/`

```
lib/
├── main.dart                  # точка входу, підключення провайдерів
├── models/                    # Question, SavedFile, InProgressQuiz, SessionResult
├── providers/
│   ├── quiz_provider.dart     # стан квізу: перемішування, відповіді, пауза/продовження
│   ├── settings_provider.dart # API ключ і вибір моделі Gemini
│   └── tts_provider.dart      # озвучення (flutter_tts)
├── screens/                   # home, library, quiz, result, history, settings
├── services/
│   ├── file_import_service.dart # вибір і парсинг JSON
│   ├── gemini_service.dart      # запити до Gemini API
│   ├── remote_quiz_service.dart # завантаження index.json і квізів з бібліотеки
│   └── storage_service.dart     # shared_preferences
└── widgets/answer_option.dart
```

Залежності: `provider`, `shared_preferences`, `file_picker`, `http`, `intl`, `flutter_tts`. SDK: Dart `^3.9.0`.

## Запуск

```bash
flutter pub get
flutter run
```

### Gemini (необов'язково)

1. Отримайте API ключ у [Google AI Studio](https://aistudio.google.com/).
2. У застосунку відкрийте **Налаштування**, вставте ключ у поле «API ключ» і збережіть.
3. Застосунок завантажить список моделей `gemini*`; оберіть одну зі списку. Вибір зберігається локально.
4. Після відповіді на питання можна запросити пояснення.

## Бібліотека квізів

Кнопка **«Бібліотека квізів»** на головному екрані відкриває список мов і квізів з публічного репозиторію [MIt9/quiz-library](https://github.com/MIt9/quiz-library). Квіз завантажується, проходить ту саму валідацію, що й файл з диска, і потрапляє в «Збережені файли», тож далі працює офлайн.

- Список береться з `index.json` у корені репозиторію; останній отриманий список кешується й показується без мережі.
- Інший репозиторій можна підключити в **Налаштуваннях** (поле «URL репозиторію», лише `https`). Він має мати ту саму структуру: `index.json` та папки мов із файлами квізів.
- Шляхи файлів з `index.json` обмежені межами репозиторію (без абсолютних шляхів, `://` та `..`).

## Правила формування квізу

Файл — це JSON-масив об'єктів, кожен об'єкт — одне питання. Розширення `.json`, кодування UTF-8.

```json
[
  {
    "id": "1",
    "question": "Яка HTTP-відповідь означає 'не знайдено'?",
    "options": ["200", "403", "404", "500"],
    "correct_index": 2
  },
  {
    "id": 2,
    "question": "Що таке REST API?",
    "options": [
      "Архітектурний стиль для побудови веб-сервісів через HTTP",
      "База даних для зберігання запитів",
      "Мова програмування для серверної розробки",
      "Протокол шифрування даних"
    ],
    "correct_index": 0
  }
]
```

| Поле            | Тип                | Вимога                                                              |
|-----------------|--------------------|---------------------------------------------------------------------|
| `id`            | рядок або число    | Унікальний ідентифікатор; число перетворюється на рядок             |
| `question`      | рядок              | Текст питання                                                       |
| `options`       | масив рядків       | Рівно 4 варіанти                                                    |
| `correct_index` | ціле число         | Індекс правильного варіанта в `options`: від 0 до 3 (0 = перший)    |

### Валідація

Однакова для файлів з диска й з бібліотеки (`Question.parseList` у `lib/models/question.dart`). Помилка називає номер питання, наприклад `питання №2: поле "correct_index" має бути цілим числом від 0 до 3`; файл у такому разі не імпортується.

- Корінь файлу — масив, кожен елемент — об'єкт; порожній масив відхиляється.
- `id` обов'язковий (непорожній рядок або число) і унікальний у межах файлу.
- `question` — непорожній рядок.
- `options` — рівно 4 непорожні рядки.
- `correct_index` — ціле число від 0 до 3 (рядок `"2"` або `2.5` не підійдуть).

### Генерація квізу через ШІ

Попросіть ШІ вказавши:

- **тему** (Flutter, SQL, алгоритми, системний дизайн);
- **кількість** питань;
- **рівень** (junior / middle / senior);
- повернути **лише валідний JSON-масив** у форматі вище, без markdown-огорож і пояснень навколо, рівно 4 варіанти, `correct_index` від 0 до 3, унікальні `id`.

Приклад запиту: «Згенеруй 20 питань з SQL рівня middle у форматі JSON-масиву: `id`, `question`, `options` (рівно 4), `correct_index` (0-3). Поверни тільки JSON».

Перед імпортом перевірте, що відповідь є коректним JSON (наприклад, у будь-якому JSON-валідаторі).
